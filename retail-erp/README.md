# ALREDFANI RETAIL ERP

نظام إدارة متجر عربي RTL مبني بـ PHP 8 وMySQL/MariaDB. مجلد `retail-erp` هو تطبيق التشغيل الفعلي، أما `retail-erp-pages` فهو عرض تجريبي ثابت لا يشغّل PHP ولا يتصل بقاعدة البيانات.

## التثبيت على InfinityFree أو استضافة PHP
1. أنشئ قاعدة MySQL من لوحة الاستضافة.
2. استورد `database/schema.sql`.
3. انسخ `config/local.example.php` إلى `config/local.php` وعدّل بيانات قاعدة البيانات على الاستضافة. **لا ترفع ملف local.php إلى GitHub.**
4. ارفع محتويات مجلد `retail-erp` إلى مجلد الموقع.
5. افتح `install.php` وأنشئ حساب المالك الأول. اسم المستخدم الافتراضي في نموذج التهيئة هو `alredfani`؛ أدخل كلمة المرور داخل النموذج مباشرة.
6. بعد نجاح التهيئة احذف `install.php` من الاستضافة فوراً.
7. سجّل الدخول من `index.php?p=login`.

## حساب المالك
حساب المالك المنشأ عبر المثبّت يحمل دور `owner` وصلاحيات إدارة مساحة العمل والفروع والمستخدمين. تُخزّن كلمة المرور باستخدام `password_hash` ولا تُكتب داخل ملفات المصدر أو المستودع.

## GitHub Pages
GitHub Pages لا يشغّل PHP أو MySQL. رابط Pages مخصص للمعاينة الثابتة فقط، ولا يصلح لتسجيل دخول حقيقي أو لحفظ بيانات المتجر. استخدم تطبيق PHP المستضاف لتشغيل النظام الفعلي.

## الأمان
- لا ترفع `config/local.php` أو كلمات المرور أو نسخ قواعد البيانات إلى المستودع.
- استخدم HTTPS.
- احذف ملف التثبيت بعد التهيئة.
- احتفظ بنسخ احتياطية خارج مجلد الويب.
- راجع صلاحيات كل دور قبل تشغيل المتجر ببيانات حقيقية.

## حدود الإصدار
تشمل النواة الدخول والمالك ومساحة العمل والفروع والمنتجات ونقطة البيع والمخزون والعملاء والموردين والمصروفات والتقارير الأساسية. المشتريات المتقدمة والمرتجعات والورديات والمحاسبة الشاملة والصلاحيات الدقيقة لكل عملية لا تزال بحاجة إلى استكمال واختبار؛ لا تعتبر مكتملة لمجرد وجود ملفات المشروع.
