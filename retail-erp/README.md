# ALREDFANI RETAIL ERP
نظام عربي لإدارة البيع بالتجزئة متعدد مساحات العمل والفروع، مبني بـ PHP 8 وMySQL/MariaDB.

## التثبيت
1. أنشئ قاعدة MySQL.
2. استورد `database/schema.sql`.
3. انسخ `config/local.example.php` إلى `config/local.php` وأدخل بيانات الاتصال.
4. ارفع مجلد retail-erp إلى الاستضافة وافتح install.php.
5. أنشئ المالك ثم احذف install.php.
6. سجل الدخول من index.php.

لا يحتاج Composer أو Node. مناسب لـ InfinityFree والاستضافات المدفوعة/VPS التي توفر PHP 8 وPDO MySQL.
الإصدار الحالي أساس تشغيلي أولي: حسابات ومساحات عمل وفروع ومنتجات ومخزون ومبيعات نقدية وتقارير أولية. لا تعتبر المحاسبة الشاملة أو Offline المتزامن أو المشتريات والمرتجعات المتقدمة مكتملة بعد.
