# ALREDFANI RETAIL ERP — GitHub Pages Edition

واجهة عربية RTL متجاوبة لإدارة عمليات متجر تجريبي من المتصفح، مبنية دون إطار عمل أو اعتماد على خادم PHP.

## رابط التشغيل
https://helmyalredfani.github.io/ALREDFANI-CONSTRUCTION-MANAGEMENT/

## وظائف الإصدار 2.0
- لوحة تحكم ومؤشرات للمبيعات والفواتير وقيمة المخزون.
- إدارة المنتجات: إنشاء وتعديل، SKU، باركود، تصنيف، وحدة، تكلفة، سعر بيع، وحد إعادة الطلب.
- نقطة بيع متعددة الأصناف مع سلة، كميات، خصم، عميل، وطريقة دفع.
- إنشاء فاتورة برقم مرجعي وطباعة الفاتورة.
- خصم المخزون تلقائياً عند إتمام البيع والتحقق من توفر الكمية.
- سجل المبيعات والبحث وتصدير CSV.
- إدارة أرصدة المخزون والتسويات وسجل الحركات.
- قوائم العملاء والموردين.
- تسجيل المصروفات.
- تقارير فترة: المبيعات، تكلفة البضاعة، المصروفات، الربح التقديري، والأصناف الأكثر مبيعاً.
- نسخ احتياطي JSON واستعادة البيانات، مع ترحيل تلقائي للبيانات من إصدار Pages السابق.
- إعداد اسم المنشأة والعملة.
- واجهة متجاوبة للهواتف والأجهزة المكتبية.

## النشر
المصدر مضبوط على GitHub Actions. أي تحديث داخل `retail-erp-pages/**` يشغّل سير العمل:
1. التحقق من وجود HTML وCSS وJavaScript.
2. فحص صياغة JavaScript بواسطة `node --check`.
3. رفع مجلد `retail-erp-pages` ونشره على GitHub Pages.

## حدود مهمة قبل الاستخدام التجاري
هذه النسخة **محلية تجريبية وليست نظام ERP متعدد المستخدمين**:
- تحفظ البيانات في Local Storage في المتصفح الحالي فقط.
- لا يوجد تسجيل دخول أو صلاحيات أو عزل مستخدمين.
- لا توجد قاعدة بيانات مركزية أو تزامن بين الأجهزة والفروع.
- يمكن للمستخدم أو المتصفح تعديل البيانات المحلية؛ لا يوجد تحقق خادمي أو سجل تدقيق موثوق.
- لا تتضمن دورة مشتريات كاملة أو مرتجعات أو ضرائب أو محاسبة دفترية أو إقفال صندوق.
- التقارير تقديرية وتعتمد على تكلفة المنتج المسجلة عند البيع، ولا تمثل قوائم مالية مدققة.
- حذف بيانات المتصفح أو تعطل الجهاز قد يؤدي إلى فقدانها؛ نزّل نسخة احتياطية بانتظام.

**لا تحفظ بيانات عملاء حساسة أو تعتمد على هذه النسخة كسجل تجاري رسمي.**

## الانتقال إلى تشغيل احترافي فعلي
للوصول إلى نظام آمن متعدد المستخدمين والفروع، يلزم Backend وقاعدة بيانات مركزية، مع مصادقة وصلاحيات مفروضة من الخادم، ومعاملات مخزون ومبيعات ذرية، ونسخ احتياطي دوري. يمكن تطوير نسخة PHP/MySQL الموجودة في `retail-erp/` أو اختيار خدمة خلفية مناسبة. لا توضع مفاتيح سرية أو كلمات مرور داخل ملفات Pages العامة.
